# 04 — Tercer nivel FEAT: comparación entre sujetos

**Estado: PENDIENTE.** Cada participante debe aportar los efectos apropiados por contraste (habitualmente el segundo nivel de sus dos runs).

Definir de antemano diagnósticos/grupos, exclusiones, covariables y contrastes; utilizar un modelo que represente la variabilidad entre participantes (p. ej., efectos mixtos FLAME). No introducir runs como participantes independientes ni asumir grupos por el identificador numérico.

Validar el espacio estándar común y la correspondencia de contrastes antes del análisis.
